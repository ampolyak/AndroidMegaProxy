## English

- Added passphrase-protected SSH keys for destination and jump hosts, with connection prompts or optional local saving in the profile editor, while excluding passphrases from exports and leaving encrypted PKCS#8 unsupported.
- Added a VPN apps shortcut below the active profile that shows all-app routing or the number of selected apps and opens routing settings.
- On Android 10+, split tunneling now defaults to Standard ownership checks and all-app routing leaves checks off unless an on/off choice is already saved.
- Renamed Advanced source validation to Strict and changed Standard to recheck UDP ownership after a pause of at least one second in outgoing traffic, so continuous traffic can keep stale permission active.
- Fixed ownership validation for configuration-selected apps without launcher activities so their traffic is accepted when selected for split tunneling.
- Changed the default TLS fingerprint from Chrome Android to Firefox Android while preserving explicitly selected presets.
- Configuration exports now use JSON v9 with Android-specific settings in an Android section, while imports retain legacy compatibility and subscriptions validate both v8 and v9.
- Stopping VPN startup now cancels proxy DNS lookup, and subscription requests now disconnect on cancellation or after 45 seconds per source, including stalled headers and decompression.
- Diagnostic log exports now capture a fixed snapshot without blocking new log writes when the destination is slow.
- Profile, SSH key and log file operations now show an error instead of crashing when the system file picker is unavailable or access is denied.

## Русский

- Добавлена поддержка защищённых парольной фразой SSH-ключей конечного и промежуточного серверов с вводом фразы при подключении или сохранением в редакторе профиля, при этом фразы исключены из экспорта, а зашифрованный PKCS#8 не поддерживается.
- Под активным профилем появился переход «Приложения VPN», показывающий режим всех приложений или число выбранных и открывающий настройки маршрутизации.
- На Android 10+ для раздельного туннелирования по умолчанию включена стандартная проверка владельца трафика, а для всех приложений она выключена, если выбор ещё не сохранён.
- Расширенный уровень проверки источника переименован в строгий, а стандартный теперь повторно проверяет владельца UDP после паузы в исходящем трафике не менее секунды, поэтому непрерывный трафик может сохранять устаревшее разрешение.
- Исправлена проверка владельца трафика приложений без значка запуска, выбранных через конфигурацию, чтобы их трафик разрешался при раздельном туннелировании.
- Отпечаток TLS по умолчанию изменён с Chrome Android на Firefox Android с сохранением явно выбранных пресетов.
- Экспорт конфигурации использует JSON v9 с отдельным разделом настроек Android, при этом импорт сохраняет совместимость со старыми форматами, а подписки проверяют схемы v8 и v9.
- Остановка запуска VPN теперь отменяет DNS-запрос адреса прокси, а запросы подписки закрываются при отмене или через 45 секунд на источник, включая зависшее получение заголовков и распаковку.
- Экспорт диагностического журнала теперь сохраняет фиксированный снимок и не блокирует запись новых событий при медленной работе получателя.
- Операции с файлами профилей, SSH-ключей и журналов теперь показывают ошибку вместо аварийного завершения, если системный диалог выбора файла недоступен или доступ запрещён.
